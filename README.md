# 截图 / Screen Capture

为 DSH Web UI 在对话区域右上方、与其他会话工具图标并排增加一个截图控件。点击相机图标后按当前方式截取屏幕；旁边的下拉箭头可切换截屏方式与保存位置。

## 使用

1. 在对话标题栏右侧的工具图标区找到相机图标（旁边带下拉箭头）。
2. 点下拉箭头选择：
   - **截屏方式**：划定区域、全屏、窗口。
   - **保存位置**：剪贴板、文件，或勾选「预览图片」。勾选预览后，剪贴板和文件两项不可用。
3. 点相机图标：
   - **划定区域**：macOS 直接进入系统原生全屏框选，在真实屏幕上拖动选择区域，松开即截取；`Esc` 取消。Windows/Linux 退回「冻结全屏图 + 页内拖动选择」。
   - **全屏**：直接截取主显示器并送达保存位置。
   - **窗口**：进入系统窗口选择器，鼠标悬停的窗口自动高亮边框，单击左键完成截图。
4. 结果会以提示条告知：已复制到剪贴板，或已保存到具体路径；若勾选「预览图片」，则打开居中的悬浮预览/编辑窗口。

选择会被记住（`localStorage`），下次打开沿用。

## 保存位置

- **剪贴板**：通过 Host 调用系统剪贴板（macOS 用 `osascript`，Windows 用 PowerShell，Linux 用 `wl-copy`/`xclip`）；失败时退回浏览器 Clipboard API。
- **文件**：截图完成后由 Host 弹出系统原生保存对话框，可选择目录和文件名；取消对话框则不保存、不报错。
- **预览图片**：截图完成后打开居中的悬浮预览/编辑窗口，背景变暗。工具栏使用图标按钮，提供旋转、翻转、裁剪、椭圆、矩形、箭头、文字、马赛克，以及最后的复位按钮；标注工具可选择颜色。完成后选择「复制到剪贴板」或「保存到磁盘…」。
  - **复制成功**后编辑窗口自动关闭，并提示已复制。
  - **保存成功**后编辑窗口自动关闭，并提示保存路径；取消保存或失败时窗口保持打开，可继续编辑。

## 平台与权限

- **macOS**：全屏用系统 `screencapture -x -D 1`；划定区域用 `screencapture -s` 调起系统原生全屏框选；窗口用 `screencapture -w -o` 调起原生窗口选择器（悬停高亮、单击捕获，不包含窗口阴影）；保存对话框用 `osascript` 的 `choose file name`。需要在「系统设置 → 隐私与安全性 → 屏幕录制」中允许 DeepSeek Harness；首次截图可能触发系统授权提示。
- **Windows**：用 PowerShell + `System.Drawing` 抓取虚拟桌面（含多显示器）。
- **Linux**：依次尝试 `gnome-screenshot`、`spectacle`、`grim`、`scrot`、ImageMagick `import`；剪贴板依次尝试 `wl-copy`、`xclip`；保存对话框依次尝试 `zenity`、`kdialog`、`yad`。
- 全屏指主显示器（Windows 为整个虚拟桌面）。

## 实现

- `client.js` — 对话标题栏右侧的相机图标、下拉菜单、非 macOS 的冻结图区域选择与裁剪、结果提示。
- `server.js` — 三个精确路由，复用 `/api` 的 Host/Origin 与浏览器会话准入：
  - `POST /dsh-screen-capture/capture` → 全屏 PNG，或 macOS 原生框选/窗口选择后的 PNG（响应头 `x-capture-kind` 区分）
  - `POST /dsh-screen-capture/save` → 弹出系统保存对话框并写入所选路径（取消返回 `canceled: true`）
  - `POST /dsh-screen-capture/copy` → 写入系统剪贴板
- `cordis.patch.yml` — Bundle patch，插入 `dsh-screen-capture` 行。
- `locale/{zh,en}.json` — 插件管理器里的标题与描述。
- `icon.svg` — 插件图标。

临时截图文件放在系统临时目录，读完即删；上传路由限制 64 MiB 且校验 PNG 签名。默认文件名只保留安全字符，最终落盘路径由系统保存对话框决定。

## 已知边界

- 「窗口」模式当前仅 macOS 支持；Windows/Linux 选择后会提示不支持。
- 悬浮编辑窗口的标注是矢量绘制，旋转/翻转/裁剪时会先合并进图片；马赛克会直接涂抹到图片上。点最后的「复位」可恢复原始截图。
- 工具栏不再提供删除/清除标注按钮。
- 悬浮窗口覆盖在应用上方，背景变暗；编辑期间保持打开，只有复制/保存成功后自动关闭，也可点右上角关闭或按 `Esc`。
- 窗口截图使用 `-o` 去掉系统窗口阴影，避免透明/白色外边。
- 滚动、动画、鼠标指针不会进入截图；截图是按下快门那一刻的静态画面。
- macOS 的区域框选由系统全屏覆盖层完成，不受 DSH 窗口大小限制；Windows/Linux 的兜底选择层只在 DSH 窗口内显示整块屏幕的缩放图。
- 保存文件时如果取消系统对话框，截图不会落盘，也不会再退回浏览器下载。
- 多显示器下只截主显示器；需要其他显示器时，请把目标窗口移到主显示器后再截。
